# User Management System (PHP + MongoDB)

## Features
- User Signup
- Login Authentication
- Update Profile
- Delete Account
- Prevent Duplicate Emails
- Validation & Error Handling

## Tech Stack
- PHP
- MongoDB
- Composer

## Project Structure
/project-root
/public
/backend
/config
/models
/routes
.env
README.md

## How to Run
1. Start XAMPP
2. Start MongoDB
3. Run: composer install
4. Open browser: http://localhost/project-root/public
